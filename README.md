# 每日英语词本

一个自己用的背单词 + 日常英语短语网站，目标是在英国生活、能和本地人 small talk（适合雅思 6.5 / B2 左右）。

## 每日词表

10 天课程，每天 50 个单词 + 20 个常用句，每个单词带中文、例句和例句的整句翻译：

| 天 | 主题 |
|---|---|
| 1 | 天气与季节 |
| 2 | 问候、近况与心情 |
| 3 | 周末与爱好 |
| 4 | 吃喝与酒吧 |
| 5 | 工作与通勤 |
| 6 | 住房与邻里 |
| 7 | 旅行与度假 |
| 8 | 健康与运动 |
| 9 | 购物与花钱 |
| 10 | 聊观点与地道口语 |

页面顶部「进度」选择第几天，所有玩法都可以选「今日」或「已学复习」。

## 功能

- **听**：单词、短语、例句都能朗读，可选英音 / 美音，可调语速，有慢速播放。
- **拼写练习**：听读音后用键盘打字，字母实时对错提示。
  - `Enter` 检查 / 下一个
  - `Esc` 重听
  - `Tab` 提示一个字母
  - 拼错要照着答案再打对一遍；错过的词进「错题本」。
- **单词雨**：单词（或中文）从上往下掉，打出来就消掉；连击加分，越往后越快，漏掉的词进错题本。
- **听句填空**：听整句例句，把挖掉的词或整个词组打出来，每轮 10 题；「词义」和「整句意思」都可以点开看，答完自动显示。
- **情景对话**：咖啡店、餐厅、问路、约医生、退货 5 个场景，可以选答案，也可以自己打出回答。
- **打卡与成就**：连续学习天数、每日目标、15 个成就徽章。
- **收藏**：单词、短语旁的五角星一点即收藏（变成实心金色）；词库有「收藏」页，拼写、单词雨、听句填空都能只练收藏的内容。
- **错题本**：单独一栏，集中列出所有答错过的词，按错误次数排序；一键进入拼写、单词雨或听句填空的错题专练，答对会逐步移出。
- **句子结构**：全部 700 句例句和常用句都手工标注了主语、谓语、宾语、表语、补语、状语，以及插入语、反意疑问、There 引导词、固定说法，用彩色下划线和小标签显示，可在词库页开关。
- **点词查询**：点句子里任意一个英文单词，或在顶部查词框输入，马上弹出中文、英文释义和例句；能认出变形（drizzling → drizzle）。词表外的词会查在线词典（dictionaryapi.dev）并附机器翻译（MyMemory），可一键加入「我加的」。
- **自己的词库**：查词时点「加入我的词库」即可，加入的词会自动收藏，保存在浏览器本地。

## 在线使用

开启 GitHub Pages 后访问：https://siyuan-she2026.github.io/English-Practice/

## 修改内置词库

打开 `index.html`，找到 `const DAYS`。每天是一个 `{t:主题, w:[单词], p:[短语]}`，单词格式 `英文|词性|中文|例句`，短语格式 `英文|中文`。

朗读使用浏览器自带的语音（Web Speech API），推荐 Chrome、Edge 或 Safari。
